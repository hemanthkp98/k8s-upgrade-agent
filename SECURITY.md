# Security Policy

## Reporting a Vulnerability

We take the security of `k8s-upgrade-agent` seriously. If you discover a security vulnerability, please do **not** disclose it in public issues, discussions, or pull requests.

### Responsible Disclosure Process

1. Go to the repository's [Security Advisories](https://github.com/hemanthkp98/k8s-upgrade-agent/security/advisories) tab on GitHub.
2. Click **"Report a vulnerability"** to open a private advisory draft.
3. Provide detailed steps to reproduce the issue, including environment details, configuration, and proof of concept if available.

### Response Timeline

- **Initial Response:** Within 48 hours to acknowledge receipt of the report.
- **Assessment & Triage:** Within 5 business days to confirm validity and severity.
- **Fix & Disclosure:** Security fixes will be released in a prioritized patch release, accompanied by an official GitHub Security Advisory.
